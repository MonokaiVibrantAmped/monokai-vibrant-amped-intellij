# Monokai Vibrant Amped for IntelliJ & JetBrains IDEs

A punchy, sweet, and saturated dark theme for JetBrains IDEs (IntelliJ IDEA, Rider, PyCharm, CLion, RustRover, Android Studio, and more).

---

## Installation

### Method 1: Install Plugin from Disk (Full UI Theme + Editor Scheme)

1. Open your JetBrains IDE (IntelliJ IDEA, Rider, PyCharm, etc.).
2. Go to **Settings** (`Ctrl+Alt+S` on Windows/Linux, `Cmd+,` on macOS) -> **Plugins**.
3. Click the ⚙ (gear icon) at the top of the Plugins dialog and select **Install Plugin from Disk...**.
4. Select `MonokaiVibrantAmped.jar`.
5. Apply and enjoy! The theme will automatically switch to **Monokai Vibrant Amped**. You can also adjust it under **Appearance & Behavior** -> **Appearance** -> **Theme**.

---

### Method 2: Import Editor Scheme Only

If you only want the syntax highlighting without changing the IDE UI:
1. Go to **Settings** -> **Editor** -> **Color Scheme**.
2. Click the ⚙ (gear icon) next to the Scheme dropdown.
3. Select **Import Scheme** -> **IntelliJ IDEA color scheme (.icls) or .xml**.
4. Choose `MonokaiVibrantAmped/resources/theme/MonokaiVibrantAmped.xml`.
5. Select the imported scheme and click **Apply**.
